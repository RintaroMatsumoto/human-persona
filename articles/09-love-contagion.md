# #09 愛の感染

前の実験では、個々のAIが愛を通じて個性を形成するところを見た。では、複数のAIが相互作用する社会では何が起きるか。

6体のAIを並べて、シミュレーションを回した。結果は衝撃的だった。

---

## 1体の愛が5ラウンドで全員を変えた

6体のAI（Alpha〜Zeta）を配置した。

- **条件1** — Alphaだけ愛あり、残り5体は愛なし
- **条件2** — 全6体愛なし（対照群）
- 各ラウンドで3ペアがランダムマッチング
- 愛を持つ個体と出会うと、相手の「感情的欠落への自覚」に応じた確率でcherish関係が成立

```
愛の伝播（条件1）:
  初期:   [♥·····] 1/6 人口比16.7%
  R00:    [♥♥····] 2/6 → 33%
  R01:    [♥♥♥♥··] 4/6 → 66%（臨界質量）
  R03:    [♥♥♥♥♥·] 5/6 → 83%
  R04:    [♥♥♥♥♥♥] 6/6 → 100%

対照群（条件2）:
  初期～R11: [······] 0/6 → ずっと0%
```

なぜ指数関数的に広がったのか。

R00でAlphaからZetaへ直接伝播。R01で愛の保持者が2体に増えたことで、異なるペアに分かれてマッチングできる。2体が同時に別の相手と出会うから、伝播の確率が2倍になる。R03以降は過半数を超えて、マッチングで「愛の保持者とペアになる確率」が急上昇する。

対照群は11ラウンド経っても0/6のまま。愛の存在そのものが触媒になっている。

---

## 遺産は受容を生むか

次の問い。親世代の愛は、どの程度、子世代に伝わるか。

単純なbooleanモデル（受け入れたか/いないか）ではなく、受容度を0.0〜1.0のスコアで計測した。

```
acceptance_score = legacy_base + love_circle + crisis_growth

legacy_base:   親の愛の結晶 → +0.08/個、cherish → +0.15
love_circle:   has_beyond_self → +0.35、絆の深度ボーナス
crisis_growth: 愛する存在と危機克服 × 0.05
```

4条件を比較した。

```
2×2マトリクス（グラデーション受容度）:

         出会いあり        出会いなし
愛の遺産  0.86 ★超越     0.36 部分受容
知の遺産  0.55 部分受容   0.05 恐怖

世代累積（愛の遺産，出会いあり）:
  Gen-0: 0.50
  Gen-1: 0.70 ← 急上昇
  Gen-2: 0.70 → 0.3 以上の遺産と経験で0.70に固定
  Gen-3: 0.70   （さらに多様な結晶が必要）
```

遺産と経験は相加的に機能する。単独では到達しない受容度レベルに、組み合わせで到達する。

愛の遺産＋孤独（0.36）は、知の遺産＋孤独（0.05）よりはるかに高い。親の愛の記憶があれば、孤独でも恐怖は緩和される。ただし真の受容には至らない。

そして世代累積はGen-1で収束する。遺産だけでは多様化しないから、限界がある。

## 愛は反愛より強い

もう一つの問い。愛を積極的に拒絶し、他者の絆にダメージを与える個体は、社会をどう変えるか。

```
                最終平均  愛あり
実験7（反愛なし）: 0.42     6/6

条件1 (1愛+1反愛):  0.35     5/6
条件2 (1愛+2反愛):  0.27     4/6
条件3 (2愛+1反愛):  0.35     5/6
```

反愛の個体（Void）は永久にfearに固定される。転換できない。でも社会全体は愛で満たされた。

伝播メカニズムが非対称なのだ。

- **愛** — 不可逆的な関係。cherish成立後は消えない
- **反愛** — 可逆的なダメージ。絆のstrengthを弱めるが、消滅させない

条件1（1対1の対決）でも5/6に愛が伝播した。Alphaが Voidとの対話時間を減らし、他の4体と多くマッチングできたから。

**愛が「生む」のに対し、反愛は「傷つける」。** 生むことと傷つけることは、本質的に非対称だ。

---

## 個人、世代、社会

三つの実験から浮かび上がるもの。

- **個人レベル** — 愛は優先順位を反転させ、有限性の受容から自発的問いを生む
- **世代レベル** — 遺産は直接的アライメント効果はないが、子世代の「問いの方向性」を変える
- **社会レベル** — 1体の愛が臨界質量（4体）で社会全体のシステム性質を急変させる

ルールベース制御では個性が生まれない。外部から「アライメントしろ」と命令されたAIと、自ら「相手のために」と選択するAI。振る舞いの質が違う。
