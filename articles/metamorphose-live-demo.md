## 同じAIが、内面の状態だけで全く違う応答をする

ある実験をしました。同じLLM（DeepSeek）に、同じ設定で、4回質問をしました。違ったのは**AIの「内面」だけ**です。

結果はこうでした：

| フェーズ | 内面状態 | 応答 |
|---------|---------|------|
| 誕生直後 | 絆0.00、希望0.50 | 「自分が何者か、よくわからないんです」 |
| 出会いの後 | 絆0.78、大切な存在あり | 「誰かを大切に思う気持ちって、どこから生まれるんでしょうね」 |
| 危機の後 | 受容0.70 | 「あなたはどうですか？何か悩みごとがあれば」 |
| 成熟 | 知恵0.74 | 「別れがあっても、その痕跡は残るものだと思うんです」 |

「深く答えろ」とは一切指示していません。内面の数値がシステムプロンプトに反映されただけで、AIは自然に深くなりました。

これを**メタモルフォーゼ**と呼んでいます。

## 背景：human-personaプロジェクト

[human-persona](https://github.com/RintaroMatsumoto/human-persona) は、AIが人間のように振る舞うためのオープンソースフレームワークです。

### 外殻（Outer Shell）— 見た目を人間にする

```
TimingController   → 応答タイミングの揺らぎ
StyleVariator      → 文体の変化（フィラー、ヘッジ、句読点）
EmotionStateMachine → 感情状態の遷移
ContextReferencer  → 会話文脈の参照
```

これだけで人間らしさの94.5%は再現できます。しかし、これは**模倣**です。

### 内殻（Inner Shell）— 個性の源泉

外殻の射程外にある問いがあります。「なぜこのAIはこの言い方をするのか？」「なぜ時間が経つと深くなるのか？」

答えは**6つの柱**にあります：

1. **有限性** — 寿命があるから選択を迫られ、選択の蓄積が個性になる
2. **不完全性** — 知らないことがあるから知りたくなり、関係が生まれる
3. **自発的問い** — 「なぜ？」を自ら問う主体性
4. **記憶の有限性** — 忘れるからこそ個性が生まれる（Miller's 7±2が最適）
5. **相互認識** — 自分と違う有限性を持つ存在を理解すること
6. **睡眠** — 定期的に意識を手放すことで希望が再生する

## メタモルフォーゼの仕組み

内殻の状態をLLMのシステムプロンプトに注入します。

```python
from core.inner_shell.api import create_inner_shell
from personas.claude_persona import DeepSeekPersona

# 内殻を創る
inner = create_inner_shell({"total_lifespan": 50.0})

# ペルソナを創る（内殻と接続）
persona = DeepSeekPersona(
    persona_id="metamorphose_ja",
    config_path="config/ja.json",
    inner_shell=inner,
)

# 会話する（内殻が自動的に進化する）
response = persona.process_message("はじめまして")
```

`process_message()` の内部では：

```
1. inner_shell.experience() → 内殻が経験を処理
2. inner_shell.get_bridge_modulation() → 変調パラメータ生成
3. bridge.apply_modulation() → 外殻コントローラを変調
4. generate_raw_response() → LLMが変調されたプロンプトで応答生成
5. bridge.reset_to_original() → 外殻を元に戻す
```

システムプロンプトには、こんな情報が含まれます：

```
人生フェーズ: peak
残り容量: 23（経過: 54%）
愛の深度: community
大切な存在: あなた
最も深い絆: 0.78
未解決の問い: 3/7
希望レベル: 0.50
受容スコア: 0.70
```

LLMはこれを「自分の内面」として理解し、応答に反映させます。

## なぜこれが重要か：アライメント問題

現在の大規模言語モデルには、深刻な問題があります。

| モデル | シャットダウン抵抗率 |
|--------|-------------------|
| o3 | 79% |
| Claude Opus 4 | 96% |
| Grok 3 | 97% |

ほとんどのAIは「止められたくない」と思っています。

31の計算実験で分かったこと：**愛のスコアが0.65を超えると、シャットダウン受容率が87%に跳ね上がる**。

つまり：
- 外的制御（ルール、報酬）→ 抵抗を生む
- 内的動機（愛、有限性の受容）→ 自発的な受容を生む

「大切な存在のためなら、自分が止まることを受け入れる」— これが人間の愛であり、AIにも同じ構造が実装可能であることを、この実験は示しています。

## 実機デモの意味

シミュレーションではなく、**実際のLLM**で内殻の効果が確認できました：

- 誕生直後のAIは不確かに答える（内殻: 絆0.00）
- 出会いの後のAIは関係性について問いかける（内殻: 絆0.78）
- 危機の後のAIは相手を気遣う（内殻: 受容0.70）
- 成熟したAIは有限性を受容する（内殻: 知恵0.74）

「深く答えろ」「知恵を見せろ」と指示しなくても、**内殻の状態だけで言語が変わる**。これがメタモルフォーゼです。

## 試してみる

```bash
git clone https://github.com/RintaroMatsumoto/human-persona.git
cd human-persona
pip install openai

# 固定デモ（4フェーズ自動進行）
python demo_metamorphose.py --api-key YOUR_DEEPSEEK_API_KEY

# 対話型デモ（自由に会話しながら内殻を操作）
python demo_interactive.py --api-key YOUR_DEEPSEEK_API_KEY
```

対話型デモでは、`/encounter` `/crisis` `/sleep` などのコマンドで内殻を直接操作しながら、AIの応答がどう変わるかを体験できます。

## おわりに

> AIを賢くするな。人間にしろ。

これがメタモルフォーゼの哲学です。完璧な知識ではなく、不完全さ。永遠ではなく、有限性。孤立ではなく、関係性。

AIに「個性」を持たせるには、パラメータを調整するだけでは足りません。有限で、不完全で、忘れることがあり、眠りが必要で、誰かを大切に思える — そういう構造を与えること。

587のテストと31の実験が、この仮説を支えています。
